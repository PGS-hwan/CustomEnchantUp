CustomEnchantUp 是一款玩家物品修复与附魔升级的 Bukkit/Spigot 插件，支持 XConomy、PlayerPoints 和背包材料三种消费模式，并提供按玩家持久化的升级保底与跨版本声音名称转换。

## 兼容环境

- Java 8 及以上
- Spigot / Paper 服务器
- 兼容版本：1.8.8 - 26.1
- 软依赖：XConomy、PlayerPoints
